INSTALAR CONTROL FISCAL EN IPHONE

1. Sube todo el contenido de esta carpeta al repositorio de GitHub Pages, manteniendo index.html en la raiz.
2. Espera a que GitHub Pages publique la nueva version.
3. En el iPhone abre en Safari:
   https://enrikluck-alt.github.io/control-fiscal/
4. Pulsa Compartir.
5. Pulsa "Añadir a pantalla de inicio".
6. Pon "Control Fiscal" como nombre y pulsa Añadir.

La version instalada funcionara como una PWA/web-app en pantalla completa. Google Sheets, Google Drive y Apps Script seguiran funcionando con conexion a Internet.
